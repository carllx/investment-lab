# 尾盘强势—隔夜延续策略验证实验 (Late-Day Overnight Momentum)

## 1. 实验目的与核心假设

### 实验目的
本实验旨在对中国 A 股市场长期流传的“尾盘强势个股隔夜延续策略”进行严谨、系统、学术级的量化验证。通过剥离民间概念神话，构建从数据、特征、撮合到回测的无未来函数实验框架，评估该策略在不同市场环境下的真实超额收益与鲁棒性。

### 核心假设 (Core Hypothesis)
> **“这套所谓‘杨永兴隔夜套利八步法’，在没有未来数据、计入交易成本和真实不可成交约束之后，是否仍具有稳定、可重复、跨市场阶段的正期望？”**

### 命名脱敏与去神话化说明
1. **摒弃个人神化**：量化研究应专注于可检验的市场规律与统计特征，而非特定个人名号或民间传奇；
2. **纠正“套利”误称**：金融学中的“套利”（Arbitrage）指利用价差无风险对冲获利。本策略本质为**单向多头持有、承担隔夜非对称跳空与系统性波动的动量延续策略**（Late-Day Momentum & Overnight Continuation），绝非无风险套利；
3. **标准化命名**：统一采用 `late-day-overnight-momentum`，以保持实验的客观性、可扩展性与跨资产对比能力。

## 2. 系统分层架构 (Architecture Layers)

实验遵循自底向上的严格分层设计，确保各层职责单一且可独立验证：

```
┌─────────────────────────────────────────────────────────┐
│ Backtest Layer (向量化快速参数扫描 + 事件驱动拟真回测)    │
├─────────────────────────────────────────────────────────┤
│ Execution Layer (T+1、滑点、流动性上限、涨跌停与集合竞价) │
├─────────────────────────────────────────────────────────┤
│ Signal Layer (as-of 14:50 盘中无未来特征提取与打分选股)  │
├─────────────────────────────────────────────────────────┤
│ Data Layer (分钟行情、盘前股本、PIT 状态、集合竞价切片)    │
└─────────────────────────────────────────────────────────┘
```

- **Data Layer (数据层)**：提供高精度分钟行情（OHLCV）、盘前对齐的历史股本（总股本/流通股本）、日内状态（ST/停牌/涨跌停价）。核心要求是 **Point-in-Time (PIT)** 安全。
- **Signal Layer (信号层)**：在 `as-of 14:50` 等盘中观测点，仅利用当时已可知数据计算特征（盘中分均换手率、量比、VWAP 偏离度、日内新高突破），输出买入候选标的。
- **Execution Layer (执行层)**：模拟真实撮合行为，支持严格位于 signal 之后的下一可成交 eligible bar 撮合或收盘集合竞价撮合；严格处理涨停无法买入、跌停无法卖出、滑点摩擦与成交量占比上限。
- **Backtest Layer (回测层)**：提供极速向量化回测（用于全市场网格扫描与消融）与事件驱动拟真回测（用于全真实约束校验与归因）。

---

## 3. 实验优先原则 (Experiment-First)

- **轻量独立**：当前阶段不引入 Qlib、OpenBB 等大型综合量化框架，避免框架复杂度和默认设置掩盖底层微观数据偏差。
- **自包含验证**：所有数据验证、信号生成与回测规则均以可独立审查的代码和协议形式落盘。

## 4. 阶段路线图 (Phase Roadmap P000–P006)

| 阶段代码 | 阶段名称 | 核心目标与内容 |
| :--- | :--- | :--- |
| **P000** | **Data Validation** | 证明能在 signal time（as-of 14:50）重建当时真实可知的数据与成交状态，无未来数据 |
| **P001** | **Baseline** | 冻结传播版规则，完成最简单、透明的基线策略回测 |
| **P002** | **Ablation** | 逐项加入/删除 gain、recent limit-up、volume ratio、turnover、cap、VWAP、relative strength、new-high→pullback，识别增量价值 |
| **P003** | **Robustness** | 开展参数微扰敏感性分析，检验在不同年份、牛熊震荡市及市值板块风格下的稳健性 |
| **P004** | **Realistic Execution** | 引入 A 股 T+1、停牌、涨跌停、无法成交、手续费、历史印花税、slippage 及失败退出后的持仓路径 |
| **P005** | **Classic Factor Controls** | 引入少量 Alpha101 / GTJA191 canonical controls，回答传播版八步法是否只是经典短周期量价效应的粗糙代理 |
| **P006** | **Kronos Challenger** | 进行 Rule only / Kronos only / Rule + Kronos challenger 对比验证（保留实验位，当前不安装/训练） |
